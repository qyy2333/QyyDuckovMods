# JumpMod - by qyy2333

**功能简介：**  
让你的角色跳得更高、更自由！支持自定义跳跃键和跳跃高度。

**功能特点：**  
- 自定义跳跃键  
- 可调节跳跃高度（1–20）  
- 实时配置生效  
- 支持第一/第三人称越肩  

**按键与配置：**  
- 默认跳跃键：Space（可自定义）  
- 跳跃高度：5（可自定义，范围 1–20）  
- 前置需求：Mod Config（推荐安装）  

**性能优化：**  
- 轻量化实现，低占用  
- 无需 Harmony 补丁  

**更新日志：**  
- v1.0：初始版本，支持跳跃键和跳跃高度
