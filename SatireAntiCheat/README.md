# 讽刺性反作弊系统 - Satire Anti-Cheat System

**作者：** qyy2333  
**版本：** 1.0  
**标签：** 恶搞、趣味、UI

---

## 🧩 模组简介
这是一个完全恶搞的“反作弊系统”模组。  
它不会真的扫描任何文件、不会上传任何信息、不会封号。  
它只是模仿某些过度反作弊游戏的做法，展示一个“正在扫描硬盘”的假消息，带来轻松一笑。

---

## 💡 主要特性
- 进入游戏数秒后自动弹出“检测报告”  
- 会随机展示幽默的“警告消息”  
- 检查桌面文件名（纯文本，不会访问隐私）  
- 完全无害，不会对系统造成任何影响  
- 界面使用 TextMeshPro 制作，效果精致  

---

## ⚙️ 技术细节
- 不读取或上传任何文件内容  
- 仅通过 Unity API 获取桌面路径  
- 所有提示内容均为预设文本  

---
