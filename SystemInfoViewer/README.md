# System Info Display - by qyy2333

**注意：**  
此 MOD 仅用于展示系统信息，不得用于任何侵犯版权、违反法律或制作恶意 MOD 的用途。请勿使用本 MOD 的源代码制作非法或未经授权的内容。  

**功能简介：**  
在游戏中显示详细系统信息、网络信息和磁盘扫描结果。

**功能特点：**  
- 显示设备名称、操作系统、CPU、内存、显卡信息  
- 显示分辨率  
- 网络信息：网卡、MAC、IPv4  
- 磁盘扫描：驱动器信息、可用空间、根目录文件  

**性能优化：**  
- 仅调用系统 API，低资源占用  
- 异常安全处理
