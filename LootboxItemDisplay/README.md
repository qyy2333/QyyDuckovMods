# Lootbox Item Display - by qyy2333

---

## 功能简介
让你能同时看到地面掉落物、附近箱子内容以及全图最高价值物品的UI增强Mod!

---

## 功能特点
- 显示地面与箱子内的物品，包括物品的稀有度、重量和价值  
- 实时显示全图最高价值物品TOP3，助你快速找到值钱货  
- 可调检测半径、字体大小、界面布局  
- 独立开关：箱子显示/掉落物显示/最高价值追踪  
- 支持中文/英文自动识别  
- 两个UI面板均可拖拽，自由调整位置  
- 需要 Mod Config 作为前置（非强制，装上后可以调整各种设置）  

---

## 按键与配置
- F3 - 显示/隐藏附近箱子和掉落物列表  
- F4 - 显示/隐藏最高价值物品TOP3面板  
- 前置需求：Mod Config（推荐安装）  

---

## 最高价值追踪说明
- 实时扫描全图所有箱子和掉落物  
- 显示前3名最有价值的物品（金银铜排名）  
- 显示物品位置、价值和实时距离  
- 自动过滤玩家仓库和宠物背包  
- 可在配置中设置价值阈值  

---

## 性能优化
- ✓ 已优化检测算法，大幅降低卡顿  
- ✓ 使用缓存机制，避免频繁扫描  
- ✓ 增量更新，只在有变化时刷新UI  

---

## 配置选项（需要 Mod Config）
- 检测半径（1-20米）  
- 检测间隔（0.05-1秒）  
- 显示箱子物品/显示地面掉落物/显示最高价值物品  
- 价值阈值（只显示超过指定价值的物品）  
- UI尺寸、字体大小调整  
- 按键自定义
